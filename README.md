# LSL Analytics Backend

FastAPI backend for the **Legends Sim League (LSL)** mobile-first analytics experience.

This project powers league-wide and team-level data for a future Android/iOS app, with response shapes designed around **ESPN-style browse flows** and quick mobile rendering.

## Current Product Direction

- **Mobile-first API**
- **LSL Poll** = primary poll (AP-style)
- **LCAA Poll** = secondary poll (Coaches-style)
- Polls are **separate from predictive/power metrics**
- Conference standings are based on **official snapshot records**
- Conference tie logic uses **conference game snapshots**
- `featured_games` and key ranking surfaces prioritize **LSL Poll**

---

## Tech Stack

- **Python**
- **FastAPI**
- **Google Sheets API** via service account
- JSON refresh artifacts for league-wide game data
